# 快速开始

## 环境要求

| 依赖 | 最低版本 | 说明 |
|------|----------|------|
| JDK | 17 | 推荐 OpenJDK 17+ |
| Maven | 3.8+ | 构建工具 |
| LLM 服务 | - | Ollama 本地模型 或 OpenAI 兼容 API |

## 编译构建

```bash
# 1. 克隆项目
git clone <repo-url> && cd jharness

# 2. 编译 jharness2
cd jharness2
mvn clean package -DskipTests
```

## 启动服务

### 使用 Ollama 本地模型（默认）

```bash
# 确保 Ollama 已启动并拉取了模型
ollama pull qwen3.5:4b

# 启动服务
java -jar jharness2-web/target/jharness2-web-0.1.0-SNAPSHOT.jar
```

### 使用 OpenAI 兼容 API

```bash
java -jar jharness2-web/target/jharness2-web-0.1.0-SNAPSHOT.jar \
  --jharness2.engine.default-base-url=https://api.openai.com/v1 \
  --jharness2.engine.default-model=gpt-4o
```

服务默认监听 `http://localhost:8080`。

## 首次调用

### 1. 注册用户

```bash
curl -X POST http://localhost:8080/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{"username": "demo", "password": "demo123"}'
```

### 2. 登录获取 Token

```bash
TOKEN=$(curl -s -X POST http://localhost:8080/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username": "demo", "password": "demo123"}' | jq -r '.token')
```

### 3. 创建会话

```bash
SESSION_ID=$(curl -s -X POST http://localhost:8080/api/chat/new \
  -H "Authorization: Bearer $TOKEN" | jq -r '.sessionId')
```

### 4. 发送消息（SSE 流式）

```bash
curl -N -X POST "http://localhost:8080/api/chat/$SESSION_ID/message" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"message": "用 Java 写一个快速排序"}'
```

响应为 SSE 事件流，每行格式为 `data: {...}\n\n`。

## 数据目录

启动后自动创建以下目录结构：

```
./data/
├── jharness2-db.mv.db   # H2 数据库文件
└── workspaces/           # 用户工作空间
    └── <userId>/         # 各用户独立目录
```

## 健康检查

```bash
curl http://localhost:8080/actuator/health
# {"status":"UP"}
```
