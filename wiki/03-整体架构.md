# 整体架构

## 分层设计

```
┌───────────────────────────────────────────────────────┐
│                   jharness2-web                        │
│  Controller / DTO / Security / SSE / Spring Boot App  │
├───────────────────────────────────────────────────────┤
│                   jharness2-storage                    │
│  JPA Entity / Repository / SessionStorage / Memory    │
├───────────────────────────────────────────────────────┤
│                   jharness2-core                       │
│  EngineRegistry / ChatService / Factory / Config      │
├───────────────────────────────────────────────────────┤
│                   jharness2-engine                     │
│  QueryEngine / LlmClient / Tool / Skill / Plugin /   │
│  MCP / Hook / Agent / Permission / Compaction / Task  │
└───────────────────────────────────────────────────────┘
```

**依赖方向**：`engine ← core ← storage ← web`（上层依赖下层，下层不感知上层）

## 模块职责

### jharness2-engine（核心引擎）

AI Agent 的核心运行时，**无 Spring 依赖**，可独立使用。

| 子包 | 职责 |
|------|------|
| `(root)` | QueryEngine、LlmClient、OpenAiClient、ConversationMessage |
| `stream/` | 流式事件类型（StreamEvent 体系） |
| `tool/` | 工具注册表、工具执行器、工具定义 |
| `skill/` | 技能注册表、技能定义 |
| `plugin/` | 插件加载器、插件清单、插件注册表 |
| `mcp/` | MCP 协议客户端、MCP 工具适配 |
| `hook/` | Hook 事件、Handler、执行器 |
| `agent/` | Sub-Agent 角色、任务、协调器 |
| `permission/` | 权限模式、权限检查器 |
| `compaction/` | 消息压缩服务 |
| `task/` | 后台任务定义、任务管理器 |

### jharness2-core（多用户管理）

将单用户的 QueryEngine 封装为多用户可并发的服务层。

| 类 | 职责 |
|------|------|
| `UserContext` | 用户会话上下文（userId + sessionId + workspace） |
| `EngineInstance` | Engine 实例包装 + 访问时间追踪 |
| `EngineFactory` | 引擎工厂接口（可替换实现） |
| `DefaultEngineFactory` | 默认工厂：完整的引擎组装流程（13 个组件） |
| `EngineConfig` | Spring 配置属性（@ConfigurationProperties） |
| `UserEngineRegistry` | Caffeine 缓存池化管理 |
| `ChatService` | 聊天服务门面（异步 + 流式回调） |
| `ChatEventDto` | 统一事件 DTO（用于 SSE 推送） |
| `StreamEventAdapter` | StreamEvent → ChatEventDto 类型安全转换 |
| `WorkspaceInitializer` | 用户工作空间目录自动创建 |

### jharness2-storage（持久化层）

基于 Spring Data JPA 的数据存储。

| 组件 | 说明 |
|------|------|
| `UserEntity` | 用户实体（账号、密码哈希、API 配置） |
| `SessionEntity` | 会话实体（消息 JSON、Token 统计） |
| `MemoryEntity` | 记忆实体（用户级知识存储） |
| `SessionStorageService` | 会话 CRUD + JSON 序列化 |
| `MemoryStorageService` | 记忆 CRUD + 关键词搜索 |

### jharness2-web（Web 入口）

Spring Boot 应用入口，暴露 HTTP API。

| 组件 | 说明 |
|------|------|
| `AuthController` | 注册 / 登录 |
| `ChatController` | SSE 流式聊天 |
| `SessionController` | 会话管理 |
| `SystemController` | 系统状态 / 配置 |
| `SecurityConfig` | Spring Security 过滤链 |
| `JwtTokenProvider` | JWT Token 签发 / 验证 |
| `JwtAuthenticationFilter` | 请求拦截 + Token 解析 |

## 请求处理流程

```
Client → HTTP Request
  │
  ├─ JwtAuthenticationFilter（Token 验证）
  │
  ├─ ChatController.sendMessage()
  │     │
  │     ├─ 构建 UserContext
  │     ├─ ChatService.chat(context, message, eventConsumer)
  │     │     │
  │     │     ├─ UserEngineRegistry.getOrCreate(context)
  │     │     │     ├─ 缓存命中 → 返回现有 EngineInstance
  │     │     │     └─ 缓存未命中 → EngineFactory.create()
  │     │     │           └─ 组装 QueryEngine + 所有子系统
  │     │     │
  │     │     └─ engine.submitMessage(prompt, streamCallback)
  │     │           │
  │     │           └─ ReAct 循环：
  │     │               ├─ LLM 调用 → 流式文本
  │     │               ├─ 工具调用 → 权限检查 → 执行
  │     │               └─ 结果反馈 → 下一轮决策
  │     │
  │     └─ StreamEventAdapter → ChatEventDto → SSE 推送
  │
  └─ Client ← SSE Event Stream
```

## 设计原则

- **分层解耦**：engine 无框架依赖，可独立测试；core 仅管理引擎生命周期；web 仅处理 HTTP
- **用户隔离**：每个 userId:sessionId 拥有独立的 Engine、工作空间、消息历史
- **资源保护**：引擎数量限制 + 空闲超时回收 + 危险命令黑名单
- **可扩展**：EngineFactory 接口可替换、Tool/Skill/Plugin 可动态注册
