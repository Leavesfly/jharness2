# 配置参考

## 概述

JHarness2 基于 Spring Boot 配置体系，支持 `application.yml`、环境变量、命令行参数等多种配置方式。本文档列出所有可配置项。

## 完整配置示例

```yaml
server:
  port: 8080

spring:
  application:
    name: jharness2
  datasource:
    url: jdbc:h2:file:./data/jharness2-db
    driver-class-name: org.h2.Driver
    username: sa
    password:
  jpa:
    hibernate:
      ddl-auto: update
    show-sql: false
  h2:
    console:
      enabled: true
      path: /h2-console

jharness2:
  engine:
    default-model: qwen3.5:4b
    default-base-url: http://localhost:11434/v1
    max-tokens: 4096
    max-turns: 12
    max-engines-per-user: 5
    max-total-engines: 200
    engine-idle-timeout-minutes: 30
    denied-command-patterns:
      - "rm -rf /*"
      - "sudo *"
      - "shutdown*"
      - "reboot*"
      - "mkfs*"
      - "dd if=*"
  workspace:
    root: ./data/workspaces
  security:
    jwt:
      secret: your-256-bit-secret-key-here-change-in-production
      expiration-ms: 86400000

management:
  endpoints:
    web:
      exposure:
        include: health,info
```

## 配置项详解

### 引擎配置（jharness2.engine）

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `default-model` | String | `qwen3.5:4b` | 默认 LLM 模型名称 |
| `default-base-url` | String | `http://localhost:11434/v1` | 默认 LLM API 地址 |
| `max-tokens` | int | 4096 | 单次 LLM 调用最大输出 Token |
| `max-turns` | int | 12 | ReAct 循环最大轮次 |
| `max-engines-per-user` | int | 5 | 单用户最大引擎实例数 |
| `max-total-engines` | int | 200 | 全局最大引擎实例数 |
| `engine-idle-timeout-minutes` | int | 30 | 引擎空闲超时（分钟） |
| `denied-command-patterns` | List | 见下方 | 禁止的命令模式列表 |

**默认禁止命令：**
- `rm -rf /*` — 防止误删根目录
- `sudo *` — 禁止特权命令
- `shutdown*` — 禁止关机
- `reboot*` — 禁止重启
- `mkfs*` — 禁止格式化
- `dd if=*` — 禁止磁盘写入

### 工作空间配置（jharness2.workspace）

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `root` | String | `./data/workspaces` | 用户工作空间根目录 |

### 安全配置（jharness2.security）

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `jwt.secret` | String | （必填） | JWT 签名密钥（≥256 bit） |
| `jwt.expiration-ms` | long | 86400000 | Token 有效期（毫秒，默认 24h） |

### 数据库配置（spring.datasource）

| 配置项 | 说明 |
|--------|------|
| `url` | JDBC 连接字符串 |
| `driver-class-name` | 驱动类名 |
| `username` | 数据库用户名 |
| `password` | 数据库密码 |

### JPA 配置（spring.jpa）

| 配置项 | 推荐值 | 说明 |
|--------|--------|------|
| `hibernate.ddl-auto` | `update`（开发）/ `validate`（生产） | DDL 策略 |
| `show-sql` | `false` | 是否打印 SQL |

## 环境切换

### 切换为 MySQL

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/jharness2?useSSL=false&serverTimezone=UTC
    driver-class-name: com.mysql.cj.jdbc.Driver
    username: root
    password: your-password
  jpa:
    hibernate:
      ddl-auto: validate
    properties:
      hibernate:
        dialect: org.hibernate.dialect.MySQL8Dialect
```

### 切换为云端 LLM

```bash
# OpenAI
java -jar jharness2-web.jar \
  --jharness2.engine.default-base-url=https://api.openai.com/v1 \
  --jharness2.engine.default-model=gpt-4o

# 通义千问
java -jar jharness2-web.jar \
  --jharness2.engine.default-base-url=https://dashscope.aliyuncs.com/compatible-mode/v1 \
  --jharness2.engine.default-model=qwen-max
```

### 环境变量覆盖

Spring Boot 支持通过环境变量覆盖配置（`.` 转 `_`，全部大写）：

```bash
export JHARNESS2_ENGINE_DEFAULT_MODEL=gpt-4o
export JHARNESS2_ENGINE_DEFAULT_BASE_URL=https://api.openai.com/v1
export JHARNESS2_SECURITY_JWT_SECRET=your-production-secret
export SPRING_DATASOURCE_URL=jdbc:mysql://db:3306/jharness2
```

## 性能调优建议

| 场景 | 调整项 | 建议 |
|------|--------|------|
| 高并发用户 | `max-total-engines` | 根据内存调整，每引擎约占 50-100MB |
| 长对话 | `max-turns` | 适当增大（如 20），但会增加 Token 消耗 |
| Token 节省 | `max-tokens` | 适当减小（如 2048） |
| 快速回收 | `engine-idle-timeout-minutes` | 减小（如 10），适合短对话场景 |
| 内存受限 | `max-engines-per-user` | 减小（如 2-3） |
