# 项目概述

## 定位

JHarness2 是基于 JHarness 内核构建的**多用户 AI Agent Web 服务**。它将单用户 CLI 形态的 JHarness 引擎封装为支持多用户并发的 RESTful + SSE 流式服务，适用于团队内部部署的 AI 编程助手平台。

## 核心特性

| 特性 | 说明 |
|------|------|
| **多用户隔离** | 每用户独立的 Engine 实例、工作空间、会话历史 |
| **引擎池化** | Caffeine 缓存池，支持空闲回收、容量限制 |
| **SSE 流式输出** | Server-Sent Events 实时推送 LLM 生成内容和工具执行过程 |
| **ReAct 循环** | 完整的 LLM ↔ 工具调用 ↔ 结果反馈自主决策循环 |
| **JWT 无状态认证** | 基于 Spring Security + JJWT 的轻量认证 |
| **会话持久化** | 基于 JPA 的会话和记忆数据库存储 |
| **插件系统** | 支持 Skills、Plugins、MCP 服务器动态加载 |
| **权限控制** | 三级权限模式（PERMISSIVE / DEFAULT / STRICT） |
| **消息压缩** | 长对话自动摘要压缩，控制 Token 消耗 |
| **多智能体** | Sub-Agent 协调器支持任务分发 |

## 技术栈

```
┌─────────────────────────────────────────┐
│  Spring Boot 3.3.0 + Java 17           │
├─────────────────────────────────────────┤
│  Web:  Spring Web + SSE                 │
│  安全:  Spring Security + JWT (jjwt)    │
│  存储:  Spring Data JPA + H2/MySQL      │
│  缓存:  Caffeine 3.1.8                  │
│  HTTP:  OkHttp 4.12 (LLM API 调用)     │
│  序列化: Jackson                        │
└─────────────────────────────────────────┘
```

## 模块划分

```
jharness2/
├── jharness2-engine   # AI Agent 核心引擎（无 Spring 依赖）
├── jharness2-core     # 多用户引擎管理 + SPI 抽象
├── jharness2-storage  # 数据库持久化（JPA 实体 + Repository）
└── jharness2-web      # Spring Boot Web 应用入口
```

依赖方向：`engine ← core ← storage ← web`

## 适用场景

- 团队内部 AI 编程助手平台
- 私有化部署的 AI Agent 服务
- 支持本地模型（Ollama）和云端 API（OpenAI 兼容）
- 需要多用户并发、会话隔离的 Agent 应用
