# 工具与插件系统

## 概述

JHarness2 引擎层提供完整的工具（Tool）、技能（Skill）、插件（Plugin）和 MCP 协议支持，使 Agent 具备丰富的外部交互能力。

## 工具系统（Tool）

### 架构

```
┌─────────────────────────────────────┐
│           ToolRegistry              │
│  ┌───────────────────────────────┐  │
│  │  Map<name, ToolDefinition>    │  │
│  │  Map<name, ToolExecutor>      │  │
│  └───────────────────────────────┘  │
│                                     │
│  • register(definition, executor)   │
│  • getExecutor(name)                │
│  • toApiSchemas() → OpenAI 格式    │
└─────────────────────────────────────┘
```

### ToolDefinition

工具的元数据描述，对应 OpenAI Function Calling 的 schema：

```java
public class ToolDefinition {
    private final String name;           // 工具名（唯一标识）
    private final String description;    // 描述（供 LLM 理解）
    private final Map<String, Object> parameters;  // JSON Schema 参数定义
}
```

### ToolExecutor

工具的执行接口：

```java
@FunctionalInterface
public interface ToolExecutor {
    String execute(String argumentsJson) throws Exception;
}
```

- 输入：JSON 字符串格式的参数
- 输出：执行结果的字符串表示
- 异常：由 QueryEngine 捕获并转为错误消息反馈给 LLM

### ToolRegistry

工具注册表，管理所有可用工具：

```java
public class ToolRegistry {
    // 注册工具
    void register(ToolDefinition definition, ToolExecutor executor);

    // 获取执行器
    ToolExecutor getExecutor(String name);

    // 导出为 OpenAI API 格式
    List<Map<String, Object>> toApiSchemas();

    // 列出所有工具名
    List<String> listToolNames();
}
```

## 技能系统（Skill）

技能是对工具的高层封装，提供语义化的能力描述。

### SkillDefinition

```java
public class SkillDefinition {
    private final String name;          // 技能名
    private final String description;   // 技能描述
    private final String prompt;        // 系统提示词片段
    private final List<ToolDefinition> tools;  // 关联的工具集
}
```

### SkillRegistry

```java
public class SkillRegistry {
    // 注册技能
    void register(SkillDefinition skill);

    // 获取所有技能
    List<SkillDefinition> getAllSkills();

    // 生成 System Prompt 中的技能描述段落
    String buildSkillPromptSection();
}
```

## 插件系统（Plugin）

插件是可动态加载的扩展包，可携带 Skills、Tools、Agents、Hooks 和 MCP 配置。

### PluginManifest

插件清单文件格式：

```java
public class PluginManifest {
    private String name;              // 插件名称
    private String version;           // 版本号
    private String description;       // 描述
    private List<String> skills;      // 技能列表
    private List<String> commands;    // 斜杠命令
    private List<String> agents;      // Sub-Agent 定义
    private List<String> hooks;       // Hook 处理器
    private Map<String, Object> mcpServers;  // MCP 服务器配置
}
```

### PluginLoader

从文件系统加载插件：

```java
public class PluginLoader {
    // 从目录加载插件
    LoadedPlugin load(Path pluginDir);

    // 解析清单文件
    PluginManifest parseManifest(Path manifestFile);
}
```

### PluginRegistry

管理所有已加载的插件：

```java
public class PluginRegistry {
    // 加载并注册插件
    void loadPlugin(Path pluginDir);

    // 获取所有已加载插件
    List<LoadedPlugin> getLoadedPlugins();

    // 获取指定插件
    Optional<LoadedPlugin> getPlugin(String name);
}
```

### LoadedPlugin

已加载的插件实例：

```java
public class LoadedPlugin {
    private final PluginManifest manifest;
    private final Path pluginDir;
    private final List<SkillDefinition> skills;
    private final List<ToolDefinition> tools;
}
```

## MCP 协议客户端

MCP（Model Context Protocol）支持与外部 MCP 服务器通信，动态扩展工具能力。

### 架构

```
┌──────────────┐       ┌──────────────────┐
│  McpManager  │──────▶│  McpClient       │──────▶ MCP Server
│              │       │  (per server)    │       (外部进程)
│  管理多个    │       └──────────────────┘
│  MCP 连接    │
└──────────────┘
        │
        ▼
┌──────────────────┐
│  McpTool         │  ← 将 MCP 工具注册到 ToolRegistry
│  (Tool 适配器)   │
└──────────────────┘
```

### McpTool

将 MCP 协议的工具适配为本地 ToolDefinition + ToolExecutor：

```java
public class McpTool {
    private final String name;
    private final String description;
    private final Map<String, Object> inputSchema;
    private final McpClient client;  // 所属 MCP 客户端

    // 执行时通过 McpClient 发送 tools/call 请求
    public String execute(String args);
}
```

### McpClient

与单个 MCP 服务器的通信客户端：

```java
public class McpClient {
    // 连接 MCP 服务器
    void connect(String command, List<String> args, Map<String, String> env);

    // 获取工具列表
    List<McpTool> listTools();

    // 调用工具
    String callTool(String name, String arguments);

    // 关闭连接
    void close();
}
```

### McpManager

管理多个 MCP 连接的生命周期：

```java
public class McpManager {
    // 添加 MCP 服务器
    void addServer(String name, String command, List<String> args);

    // 获取所有 MCP 工具
    List<McpTool> getAllTools();

    // 关闭所有连接
    void close();
}
```

## Hook 系统

Hook 允许在引擎关键节点注入自定义逻辑。

### HookEvent

```java
public enum HookEvent {
    USER_PROMPT_SUBMIT,   // 用户提交消息
    PRE_TOOL_USE,         // 工具执行前
    POST_TOOL_USE,        // 工具执行后
    STOP,                 // 用户取消
    SESSION_END           // 会话结束
}
```

### HookHandler

```java
@FunctionalInterface
public interface HookHandler {
    CompletableFuture<Void> handle(HookEvent event, Map<String, Object> payload);
}
```

### HookExecutor

```java
public class HookExecutor {
    // 注册 Handler
    void register(HookEvent event, HookHandler handler);

    // 触发事件（异步执行所有注册的 Handler）
    CompletableFuture<Void> fire(HookEvent event, Map<String, Object> payload);
}
```

## 多智能体协调

### AgentOrchestrator

支持将任务分发给 Sub-Agent 并行或串行执行：

```java
public class AgentOrchestrator {
    // 分发任务给指定角色的 Agent
    AgentResult dispatch(AgentTask task, AgentRole role);

    // 关闭所有 Agent
    void shutdown();
}
```

### AgentRole / AgentTask / AgentResult

```java
public class AgentRole {
    private final String name;        // 角色名
    private final String systemPrompt; // 角色系统提示
    private final List<String> tools; // 可用工具子集
}

public class AgentTask {
    private final String description; // 任务描述
    private final String context;     // 上下文信息
}

public class AgentResult {
    private final String output;      // 执行结果
    private final boolean success;    // 是否成功
}
```

## 扩展开发

### 注册自定义工具

```java
ToolDefinition def = new ToolDefinition(
    "my_tool",
    "描述这个工具的功能",
    Map.of("type", "object", "properties", Map.of(
        "input", Map.of("type", "string", "description", "输入参数")
    ))
);

toolRegistry.register(def, args -> {
    // 解析 args JSON，执行逻辑，返回结果字符串
    return "执行结果";
});
```

### 注册 Hook

```java
hookExecutor.register(HookEvent.PRE_TOOL_USE, (event, payload) -> {
    String toolName = (String) payload.get("toolName");
    // 记录日志、审计、拦截等
    return CompletableFuture.completedFuture(null);
});
```
