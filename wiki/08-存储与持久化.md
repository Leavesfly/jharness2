# 存储与持久化

## 概述

`jharness2-storage` 模块基于 Spring Data JPA 提供数据持久化能力，支持会话存储和用户记忆存储。默认使用 H2 嵌入式数据库，生产环境可切换为 MySQL。

## 数据模型

### ER 关系

```
┌──────────────┐     ┌──────────────────┐     ┌──────────────────┐
│   users      │     │  chat_sessions   │     │  user_memories   │
├──────────────┤     ├──────────────────┤     ├──────────────────┤
│ id (PK)      │     │ id (PK)          │     │ id (PK)          │
│ username (UK)│     │ userId           │     │ userId           │
│ passwordHash │     │ sessionId        │     │ project          │
│ displayName  │     │ model            │     │ title            │
│ email        │     │ title            │     │ content (TEXT)   │
│ role         │     │ messagesJson     │     │ category         │
│ enabled      │     │ messageCount     │     │ createdAt        │
│ apiKey       │     │ inputTokens      │     │ updatedAt        │
│ baseUrl      │     │ outputTokens     │     └──────────────────┘
│ preferredModel│    │ createdAt        │
│ createdAt    │     │ updatedAt        │
│ updatedAt    │     └──────────────────┘
└──────────────┘
```

### UserEntity

用户账户信息，包含认证数据和个性化 LLM 配置。

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long (PK) | 自增主键 |
| username | String(64) | 唯一用户名 |
| passwordHash | String | BCrypt 哈希 |
| displayName | String(128) | 显示名称 |
| email | String(256) | 邮箱 |
| role | String(32) | 角色 |
| enabled | boolean | 是否启用 |
| apiKey | String(512) | 用户自定义 API Key |
| baseUrl | String(256) | 用户自定义 LLM 地址 |
| preferredModel | String(64) | 偏好模型 |

**索引**：`idx_user_username` (username, UNIQUE)

### SessionEntity

聊天会话，存储完整消息历史（JSON 格式）。

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long (PK) | 自增主键 |
| userId | String(64) | 用户标识 |
| sessionId | String(64) | 会话标识 |
| model | String(128) | 使用的模型 |
| title | String(512) | 会话标题 |
| messagesJson | LONGTEXT | 消息历史 JSON |
| messageCount | int | 消息数量 |
| inputTokens | long | 累计输入 Token |
| outputTokens | long | 累计输出 Token |

**索引**：
- `idx_session_user` (userId)
- `idx_session_user_session` (userId + sessionId, UNIQUE)

### MemoryEntity

用户级记忆存储，支持按项目和类别组织。

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long (PK) | 自增主键 |
| userId | String(64) | 用户标识 |
| project | String(128) | 项目名称 |
| title | String(256) | 记忆标题 |
| content | TEXT | 记忆内容 |
| category | String(64) | 分类标签 |

**索引**：`idx_memory_user_project` (userId + project)

## 存储服务

### SessionStorageService

会话的 CRUD 操作，消息历史以 JSON 字符串形式存储。

```java
@Service
public class SessionStorageService {
    // 保存/更新会话（Upsert 语义）
    void saveSession(String userId, String sessionId, String model,
                     List<?> messages, long inputTokens, long outputTokens);

    // 查找单个会话
    Optional<SessionEntity> findSession(String userId, String sessionId);

    // 列出用户所有会话（按更新时间倒序）
    List<SessionEntity> listSessions(String userId);

    // 删除会话
    void deleteSession(String userId, String sessionId);
}
```

**Upsert 逻辑**：先查找 userId + sessionId 是否存在，存在则更新，不存在则创建新记录。

### MemoryStorageService

记忆的 CRUD + 搜索操作。

```java
@Service
public class MemoryStorageService {
    // 保存/更新记忆（按 userId + project + title 去重）
    void saveMemory(String userId, String project, String title,
                    String content, String category);

    // 列出项目下所有记忆
    List<MemoryEntity> listMemories(String userId, String project);

    // 获取单条记忆
    Optional<MemoryEntity> getMemory(String userId, String project, String title);

    // 关键词搜索（标题 + 内容模糊匹配）
    List<MemoryEntity> searchMemories(String userId, String project, String keyword);

    // 删除记忆
    void deleteMemory(String userId, String project, String title);
}
```

## Repository 接口

基于 Spring Data JPA 自动生成实现：

```java
// SessionRepository
Optional<SessionEntity> findByUserIdAndSessionId(String userId, String sessionId);
List<SessionEntity> findByUserIdOrderByUpdatedAtDesc(String userId);
void deleteByUserIdAndSessionId(String userId, String sessionId);

// MemoryRepository
List<MemoryEntity> findByUserIdAndProject(String userId, String project);
@Query("SELECT m FROM MemoryEntity m WHERE ...")
List<MemoryEntity> searchByKeyword(String userId, String project, String keyword);

// UserRepository
Optional<UserEntity> findByUsername(String username);
boolean existsByUsername(String username);
```

## 数据库配置

### H2（默认，开发/测试）

```yaml
spring:
  datasource:
    url: jdbc:h2:file:./data/jharness2-db
    driver-class-name: org.h2.Driver
  jpa:
    hibernate:
      ddl-auto: update
```

### MySQL（生产环境）

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/jharness2?useSSL=false&serverTimezone=UTC
    username: root
    password: your-password
    driver-class-name: com.mysql.cj.jdbc.Driver
  jpa:
    hibernate:
      ddl-auto: validate
    properties:
      hibernate:
        dialect: org.hibernate.dialect.MySQL8Dialect
```

## 自动时间戳

所有实体通过 JPA 生命周期回调自动管理时间戳：

```java
@PrePersist
public void prePersist() {
    Instant now = Instant.now();
    if (createdAt == null) createdAt = now;
    updatedAt = now;
}

@PreUpdate
public void preUpdate() {
    updatedAt = Instant.now();
}
```

## 会话自动保存

Engine 层通过 `sessionPersister` 回调在每轮工具执行后自动触发会话持久化，无需 Web 层主动调用：

```
QueryEngine.submitMessage()
  └─ 每轮工具执行后 → persistIfNeeded()
       └─ sessionPersister.accept(messages)
            └─ SessionStorageService.saveSession(...)
```
