# 安全认证系统

## 概述

JHarness2 采用 **JWT 无状态认证** 方案，基于 Spring Security + JJWT 实现。服务端不维护 Session 状态，所有认证信息编码在 Token 中。

## 架构

```
Client Request
     │
     ▼
┌─────────────────────────────┐
│  JwtAuthenticationFilter    │  ← OncePerRequestFilter
│  • 从 Header 提取 Token     │
│  • 验证签名和有效期          │
│  • 设置 SecurityContext     │
└────────────┬────────────────┘
             │
             ▼
┌─────────────────────────────┐
│  SecurityFilterChain        │
│  • /api/auth/** → permitAll │
│  • /actuator/health → open  │
│  • /api/** → authenticated  │
└────────────┬────────────────┘
             │
             ▼
┌─────────────────────────────┐
│  Controller                 │
│  • 从 Principal 获取 userId │
└─────────────────────────────┘
```

## 核心组件

### SecurityConfig

Spring Security 过滤链配置：

```java
@Configuration
@EnableWebSecurity
public class SecurityConfig {
    @Bean
    public SecurityFilterChain filterChain(HttpSecurity http) {
        http.csrf(AbstractHttpConfigurer::disable)
            .sessionManagement(s -> s.sessionCreationPolicy(STATELESS))
            .cors(Customizer.withDefaults())
            .authorizeHttpRequests(auth -> auth
                .requestMatchers("/api/auth/**").permitAll()
                .requestMatchers("/actuator/health").permitAll()
                .anyRequest().authenticated()
            )
            .addFilterBefore(jwtFilter, UsernamePasswordAuthenticationFilter.class);
        return http.build();
    }
}
```

**关键配置：**
- CSRF 禁用（无状态 API 无需 CSRF 保护）
- Session 策略：STATELESS
- CORS：允许所有来源（开发阶段）
- JWT Filter 在 UsernamePasswordAuthenticationFilter 之前

### JwtTokenProvider

JWT Token 的签发和验证：

```java
public class JwtTokenProvider {
    // 签发 Token
    public String generateToken(String username) {
        return Jwts.builder()
            .subject(username)
            .issuedAt(new Date())
            .expiration(new Date(System.currentTimeMillis() + expirationMs))
            .signWith(getSigningKey())
            .compact();
    }

    // 从 Token 提取用户名
    public String getUsernameFromToken(String token);

    // 验证 Token 有效性
    public boolean validateToken(String token);
}
```

**配置项：**

| 配置 | 默认值 | 说明 |
|------|--------|------|
| `jharness2.security.jwt.secret` | （必填） | HMAC 签名密钥 |
| `jharness2.security.jwt.expiration-ms` | 86400000 | Token 有效期（24h） |

### JwtAuthenticationFilter

请求拦截器，对每个请求执行 Token 解析：

```
Request → 提取 Authorization Header
            │
            ├─ 无 Header → 放行（由后续 Security 规则决定）
            │
            └─ 有 Header → 去除 "Bearer " 前缀
                            │
                            ├─ 验证失败 → 放行（返回 401）
                            │
                            └─ 验证成功 → 设置 SecurityContext
                                          → 继续过滤链
```

## 密码安全

- 使用 **BCrypt** 加密存储（Spring Security 内置 BCryptPasswordEncoder）
- 注册时：`passwordEncoder.encode(rawPassword)` → 存储哈希
- 登录时：`passwordEncoder.matches(rawPassword, storedHash)` → 验证

## 权限系统（引擎层）

除了 HTTP 层的认证外，引擎层还有工具级别的权限控制：

### PermissionMode

```java
public enum PermissionMode {
    PERMISSIVE,  // 允许所有工具
    DEFAULT,     // 默认：允许大部分，禁止危险操作
    STRICT       // 严格：仅允许白名单工具
}
```

### PermissionChecker

```java
public class PermissionChecker {
    private final PermissionMode mode;
    private final List<String> deniedCommandPatterns;

    public boolean isToolAllowed(String toolName);
    public boolean isCommandAllowed(String command);
}
```

**默认禁止的命令模式：**
- `rm -rf /*`
- `sudo *`
- `shutdown*`
- `reboot*`
- `mkfs*`
- `dd if=*`

## 安全最佳实践

1. **生产环境务必修改 JWT Secret**：默认 secret 仅用于开发
2. **CORS 收紧**：生产环境应限制允许的 Origin
3. **HTTPS**：生产环境建议使用反向代理（Nginx）提供 TLS
4. **Token 续期**：当前实现为固定有效期，可扩展为 Refresh Token 模式
5. **工作空间隔离**：用户名经过 sanitize，防止路径遍历
